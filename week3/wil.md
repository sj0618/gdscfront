# 객체 타입.
**문자열** , **객체** 가 있음.
**문자열** : 문자열 선언하려면 **쌍따옴표** , **홑따옴표**, **백틱** 사용.
**객체**: **중괄호**로 객체 선언가능. `"let kg = {};"`
**객체**는 c++의 **객체**와 크게 다르지않음.

# DOM .
`document` 를 의미하는데 `document` 는 `html` 을 의미함 .
**DOM** = **document object model** .

1.  업데이트 할 태그를 찾는다 . (`documentElement` 사용)
2.  새로운 태그를 만든다. (`createElement`사용)
3.  새로운 태그에 데이터를 넣는다.
4.  새로운 태그를 기존 태그에 추가한다.
