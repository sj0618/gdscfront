### **css**
스타일을 넣으려면 html(인라인 스타일) 을 직접 써가지고 할수도잇겟지만,  
그러려면 너무 귀찮으니깐 , 한번에 적용할려고   
css를 만든다. 내부 스타일  
```html
<style>
    h1,h2,h3,h4,h5{
        color : yellow;
        background-color: red;
    }
</style>```
이렇게 한번에 퉁쳐서 할수가 있으니깐 편하다.
근데 이렇게 한번에 하는거는 인라인스타일(직접 태그안에다가 쓰는거)
보다 우선순위가 밀린다(c언어 전역변수 지역변수 느낌임)  

근데 파일이 여러개가 있으면 내부스타일도 안됨.  
그래서 
### **외부 스타일 방식 CSS**
를 만들었다.
사용방법은 css 파일 (style.css)를 만들고 , 거기다가  
인라인스타일이랑 비슷하게 쓰면 된다.  
```html
<link rel = "stylesheet" href="style.css">
```
를 head태그 안에 작성을 해줘야 적용이됨.

### 색상
색상을 지정하는방법에는 RGB와 HEXCODE 로 지정 가능.  
R,G,B를 각각 (256,256,256) 으로 표현하고 (xx,xx,xx)로 16진법으로 구현도 가능

### Class
태그 안의 내용을 대상으로 스타일링을 바꿀 수 있음.  
같이 관리할 내용을 묶어가지고 CLASS로 함께 관리함.  
하나만 바꾸면 다같이 바껴서 편하다.
